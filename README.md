# 🛡️ Dashimaki Anti-Grief

Minecraft Bedrock Edition向けの、荒らし・グリッチ対策アドオンです。

マルチプレイワールドで起こりやすいコンテナ荒らし、危険物の持ち込み、バンドルを利用した不審な操作などを監視・保護します。

制作: ダシマキ

---


# 🔐 コンテナロック

木の棒を持った状態で、

**しゃがむ + コンテナを右クリック**

すると、そのコンテナをロックできます。

もう一度同じ操作をするとロックを解除できます。

## 対応コンテナ

- チェスト
- トラップチェスト
- 樽
- かまど
- 溶鉱炉
- 燻製器
- シュルカーボックス

ダブルチェストにも対応しています。

---

# 🚨 ロックコンテナ監視

ロックされたコンテナに対して、各種監視・保護を行います。

### コンテナ破壊通知

ロックされたコンテナが破壊されると管理者へ通知します。

### 移動・消失監視

ロックされた座標からコンテナが消えた場合も検知します。

そのため、

- ピストン
- 粘着ピストン
- TNT
- 爆発
- その他の原因による消失

なども監視できます。

検知時には、

- コンテナ所有者
- コンテナの座標
- 検知地点に最も近いプレイヤー

を管理者へ通知します。

例:

text
[警告] dashimaki4797 のロック済みコンテナが移動または消失しました。
対象コンテナの座標 100,64,200　最寄りのプレイヤー名 PlayerA
